# Issue 形状

## 父 PRD

- 问题与用户价值
- 目标和可度量结果
- 编号 `REQ-*` 需求
- 范围与非目标
- 接口、兼容性、失败行为和安全决策
- 依赖、风险和最高有效测试接缝
- 编号 `AC-*` 验收标准
- 迁移、回滚和决策记录

## 可执行 Task

- 父 PRD 与覆盖的 `REQ-*` / `AC-*`
- 一个端到端可观察行为
- 包含与排除范围
- 公共接口影响
- 可独立检查的验收标准
- 精确聚焦与最终验证命令
- 依赖、阻塞、安全风险和回滚边界
- 完成交接字段

除非路径或实现约束用于避免已知错误，否则不要在需求中预写实现。禁止使用“可用”“正确”
或“测试充分”等不可度量验收。
